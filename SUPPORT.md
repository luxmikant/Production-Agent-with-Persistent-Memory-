# Support

Thanks for using StillMind.

## Where to get help

- **Documentation** — start with the [README](./README.md) and `docs/`.
- **Issues** — search open issues before filing a new one; use the issue
  templates under `.github/ISSUE_TEMPLATE/`.
- **Cross-repo questions** — this is a hackathon/demo project; answers are
  best-effort and may be slow.

## What is not supported

- This is **not** medical advice. StillMind provides non-clinical lifestyle,
  meditation, and schedule guidance only.
- There is no SLA, no guaranteed maintenance, and no paid support offering.

## Scope of effort

Active development happens on `main`. Feature work, bug fixes, and review of
community PRs happen on a best-effort basis. Please keep issues small and
reproducible to get help faster.
